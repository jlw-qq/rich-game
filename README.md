# 城市大富翁

**10 分钟，和朋友争夺城市地产。**

一个在浏览器里玩的大富翁。掷骰买地、盖楼收租、和对手讨价还价，最先攒到 30,000 元的人拿下这座城市。

## 怎么玩

- **开短局**：约 10 分钟。开局每人随机分到 2 块地，租金翻倍，有人总资产达到 30,000 元就结束。2–5 人，可以和 AI 打，也可以几个人轮流用同一台电脑。
- **和朋友联机**：每人用自己的手机或电脑。房主创建房间，把 4 位房间码告诉朋友。断线或刷新后会回到原来的座位。
- **今日挑战**：每天一局，所有人玩的是同一个开局和同一串骰子，比谁的成绩好。每局结束都会给出挑战码，发给朋友就能玩到同一局。

棋盘有 40 格，其中 22 块地产，分 8 个颜色组。凑齐一组才能盖楼，楼最高 4 级。除了买地和收租，还有：

- **拍卖**：有人停在无主地上不买，这块地立刻开拍，所有人轮流加价，最后留下的人按出价买下。
- **城市事件**：抽到时三选一，可以稳拿一笔钱、掷骰赌一把，或者免费升级一块地。
- **交易**：掷骰前可以和任何玩家交换地产、现金和出狱卡。
- **抵押和变卖**：现金不够时卖楼、抵押地产来还钱，还不上就破产。

更喜欢慢慢玩的话，在「更多设置」里可以选经典长局：玩到只剩一人，或者打满 100 轮。

## 运行

需要 Node.js 22 或更新的版本。

```sh
npm install
npm run dev       # 单机开发：打开 http://localhost:5173
```

联机要启动服务器。服务器同时提供网页和联网连接：

```sh
npm run server    # 先构建网页，再在 8787 端口启动
```

启动后会打印本机地址和局域网地址，同一个 Wi-Fi 下的人用浏览器打开局域网地址就能加入。第一次运行时 Windows 防火墙会询问，选「专用网络」。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 端口 |
| `HOST` | `0.0.0.0` | 监听地址。只想自己测试时设为 `127.0.0.1` |
| `DATA_DIR` | `server-data/rooms` | 房间存盘目录。服务器重启后从这里读回房间 |

开发联机功能时可以同时运行 `npm run dev` 和 `npm run server`，开发服务器会把联网连接转给 8787 端口。

## 代码结构

代码分三层，只能从上往下引用，`tests/architecture.test.js` 会检查：

- `src/data/`：配置（棋盘、卡牌、规则、模式）和存档格式。
- `src/logic/`：规则、回合状态机、AI、挑战码、联网房间。不依赖浏览器，可以直接在 Node 里运行和测试。所有随机数都来自种子，所以同一个挑战码能复现同一局。
- `src/view/`：Canvas 棋盘、动画、界面和音效。
- `server/`：联网服务器。对局在服务器上运行，玩家只发操作，服务器检查后执行，再把结果发给所有人。

技术栈：原生 JavaScript（ES 模块）、Canvas 2D、Vite、Vitest，服务器用 [ws](https://github.com/websockets/ws)。
